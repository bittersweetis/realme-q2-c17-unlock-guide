# 发布与隐私

源码目录可供上传 GitHub；本地完整文件夹另带 Windows 运行依赖及厂商回退原包。按用户要求，后续直接交付文件夹，不再生成新的整包 ZIP。本 GitHub 仓库只提交经检查的公开源码；本地固件和工具依赖没有上传。

公开包使用允许清单生成，没有复制私人 4.48 GB 归档。打包时检查了文件名、文本及实际设备标识，不含 phone backup、hwparam、DA 状态、NV、手机镜像、账户或验证码资料。

**运行过工具后，请不要把整个工作目录重新压缩上传。** MTKClient 会在运行目录生成 hwparam、`.state` 和日志，备份和候选都保存在 private。`.gitignore` 能帮助避免 Git 误提交，但不能保护手动压缩、已经被 Git 跟踪的文件或截图。

再次发布应从源码清单重建，并检查：

- `private/` 下只有 README，没有真实备份、候选、身份或日志。
- 源码提交中没有 hwparam.json、`.state`、真实手机 *.bin/*.img、*.ozip、固件 ZIP 或个人截图；本地 `firmware/oplus_ota_downgrade.zip` 由 `.gitignore` 排除，不能当成项目的 AGPL 源码。
- 保留自有及第三方许可证、算法来源、版本和验证范围。
- 原型实测与公开整理版测试分开说明，不把离线 PASS 写成另一台手机已刷机验证。
- 命令、配置和哈希修改后重新运行测试；对新机型的适配单独记录，不扩大原有成功结论。

问题反馈只需要型号、版本、错误信息、脱敏结果和复现步骤。不要上传 MEID、CID/序列号、NV、完整 GPT UUID、账户或原始全量日志。
